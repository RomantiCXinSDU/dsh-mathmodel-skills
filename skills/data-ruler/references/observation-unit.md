# 观察单位与多层观测决策（data-ruler 参考）

## 来源
data_profiler §5 Composite Key Audit 报告的组合键唯一率链。

## 判断规则
1. 若"对象"唯一率显著 < 1，说明存在多层结构；
2. 找到"接近唯一"的层级（唯一率≈1）作为"记录唯一键"；
3. **独立样本单位** = 最高有意义层（通常是对象/患者，若题目按事件则按事件）；
4. 同一事件(如一次抽血)的多条检测记录 → 不是独立样本，须聚合或按事件建模；
5. 题目意图决定观察单位：预测个体→对象层；分析时点→事件层。

## 例（2025 NIPT）
- 孕妇代码唯一率 0.24 → 对象层高度重复；
- +抽血次数 0.92 → 大部分在一次抽血一行，但仍有重复；
- +日期 0.98 → 接近唯一；
- +序号 1.00 → 记录唯一键。
- 结论：结构为 [孕妇 → 抽血事件 → 检测记录]，同一抽血事件多条检测记录须按事件聚合，独立样本按孕妇计。

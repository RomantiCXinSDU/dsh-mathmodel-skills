# 数据规则判断标准（data-ruler 参考）

| # | 规则 | 判断标准/阈值 | 常见结论 |
|---|---|---|---|
| 1 | 样本独立性 | 同一 ID 多条观测 | 聚合（取首次/达标那次）或分层模型 |
| 2 | 时间顺序 | 列含时间戳/批次 | 保留顺序，纵向处理 |
| 3 | 缺失处理 | MCAR(随机)可删/可填；MAR/MNAR 需说明机制 | 给填法(均值/中位数/插补)或删除理由 |
| 4 | 异常值 | IQR 或领域范围 | 真异常删/标记；真实极端值保留说明 |
| 5 | 共线性 | |r|>0.8 或 VIF>10 | 去除/合并/正则化 |
| 6 | 数据泄漏 | 字段含"结果/未来信息" | 建模剔除，仅用于评价 |
| 7 | 样本量 | 特征数:n 超 1:10 需警惕 | 限复杂度、降维、正则化 |
| 8 | 类别不平衡 | 正负比 >1:5 | 类权重/SMOTE/调阈值/用 AUC |
| 9 | 变量可用性 | 全空/近常数/编码混乱 | 剔除 |
| 10 | 复杂度上限 | 综合 3/7/8 | 给"最多到哪一档模型"结论 |

每条输出格式：
```
【规则1 样本独立性】同一 ID 多次采血，观测不独立。
依据：ID 列 37% 的 ID 出现 ≥2 条记录（数据概况 §6）。
对建模的影响：回归须先按 ID 聚合或加随机效应，否则标准误被低估。
```

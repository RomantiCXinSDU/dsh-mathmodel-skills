# NIPT 数据与建模坑位清单（共享参考）

> 针对 2025 国赛 C 题（NIPT 时点选择与胎儿异常判定）及同类题。每个环节读本文件，避免踩坑。

## 数据层面
1. **一人多次采血/多次检测** → 观测不独立。须按 ID 聚合（取首次/达标那次）或混合效应/生存分析。
2. **测序失败** → 不是随机缺失，是"结果缺失"，可能偏倚（失败者常是浓度低者）。要分析失败模式，不能直接丢弃。
3. **达标时间反推** → "最早达到 4%"要从多条记录**首达判定/插值**，不能拿某次测量值当达标时间。
4. **Y 浓度仅男胎有** → 女胎行的 Y 是"不适用"，不是"缺失"。性别列切分后再分析。
5. **AB 列仅女胎有** → 同理，是女胎异常判定的标签。
6. **女胎异常样本不平衡** → 类权重 / SMOTE / 调阈值，报 AUC + 查准查全，不只看准确率。
7. **BMI 分组** → 分位数/聚类，保证组间可比、组内同质、边界可解释（临床合理性优先于统计好看）。
8. **身高/体重→BMI 共线** → 三者不可同时入回归，选 BMI 或单独身高体重。

## 模型层面
9. **问题1**：先 Pearson/Spearman 相关，再线性/非线性回归 + 显著性检验（t/F、p、R²、残差诊断）。别直接上 ML。
10. **问题2 最早达标时间**：用首达时间建模（生存分析/分位数回归），别拿"某次测量值≥4%"当达标时间。
11. **问题3 多因素+误差+达标比例**：误差当**分布**处理（噪声/置信区间），达标比例是**概率**（CDF），不是点估计。
12. **问题4 女胎分类**：逻辑回归起步 + 不平衡处理 + 特征（Z 值/GC 含量/读段数比例/BMI）+ 误判代价分析。
13. **"分析检测误差的影响"** 是每问的高频要求 → 显式扰动/误差传播/蒙特卡洛。
14. **硬阈值**：Y≥4% 达标线、孕周 10~25 可测、风险早(≤12周)/中(13-27)/晚(≥28)分级——必须进模型，别丢。

# 顶刊标准拆题检查清单

> 对标顶级期刊论文的 Problem Statement / Research Questions 节：一个问题陈述合格的标志是——读者不看原文也能精确复现任务，且每个研究问题都可判定"答没答出来"。
> **克制原则**：本清单只刻画"题目要什么"，任何"怎么做"的信息（方法名、方法版图、数据画像、倾向建议）出现即废稿。

## 目录
- 一、逐句覆盖（可追溯性）
- 二、研究问题改写（可判定性）
- 三、数学元素中性角色
- 四、约束分层
- 五、术语表
- 六、陷阱与歧义清单
- 七、提交人工关卡①的裁决项（无倾向版）
- 八、三遍精读法（操作流程）
- 九、Qi 卡片（每小问一张）
- 十、全局符号表（跨小问统一）
- 十一、题面附件信息引用边界

## 一、逐句覆盖（可追溯性）
- [ ] 题目正文逐句编号，每句要么归入某个 R 编号，要么标注"背景信息"
- [ ] 每个 R 编号反向标注原文出处（页码/段落/句号）
- [ ] 附件说明、字段说明同样逐句过一遍（小问常藏在附件说明里）——**只读题面的说明文字，不打开数据文件做统计**

## 二、研究问题改写（可判定性）
每小问改写为三要素齐全的研究问题：
- **输入**：给什么数据/条件
- **输出**：要交出什么（数值/关系/方案/判断）
- **成功判据**：论文必须交付什么才算了结这一问（只写交付物；**禁止写验证方式、精度阈值、评价指标选法**——那是下游的事）
- 三要素缺任何一个 → 标"需人工裁决"，进第七节清单，禁止自行脑补

## 三、数学元素中性角色（八类）
- [ ] 已知量（题目给定的事实/数值/关系）
- [ ] 待求量（题目要求算出的对象）
- [ ] 响应变量（被解释/被预测的对象）
- [ ] 待解释变量（可能的影响因素）
- [ ] 待优化量（需要选优的对象，如时点、边界、配额）
- [ ] 待确定规则（题目要求给出的方案/判定方法）
- [ ] 目标（论文必须交付什么，单目标还是多目标）
- [ ] 约束（等式/不等式/逻辑约束）
- 某一类为空也要显式写"无"，防止漏想
- **禁用词**：决策变量 / 状态变量 / 参数标定 / 控制变量——这些预设了模型结构，属于下游选模的活

## 四、约束分层
- **显性约束**：题目明文写的（逐条引用原文）
- **隐性约束**：领域常识/物理意义隐含的（如概率∈[0,1]、人数为整数、时间不可逆），逐条列出并标注"（推断）"
- **需假设处**：题目没说清、建模必须补的，只标注"此处需假设：___"，不写假设内容

## 五、术语表
- [ ] 题目专有名词、缩写、行业术语逐条定义
- [ ] 每个概念指定全文唯一符号（中英文对照）
- [ ] 与题面附件字段名对齐（字段原名 ↔ 术语 ↔ 符号）——只依据题面的字段说明文字

## 六、陷阱与歧义清单
常见陷阱模式（逐项排查）：
- 单位/量纲不统一
- 时间口径（自然日/工作日、财年/日历年、时区）
- 分类变量的隐藏序关系
- "不少于/不低于/约"等模糊量词的具体数值含义
- 小问之间的依赖与数据复用限制
- 题目暗示的结果呈现要求

## 七、提交人工关卡①的裁决项（无倾向版）
汇总所有"需人工裁决""待确认"条目，每条**只**给：
- 歧义点原文 + 出处
- 2~3 种可能解读
- 各解读对后续建模的影响（陈述事实，不评价优劣）
- **禁止出现"建议""倾向""推荐"字样**——裁决权完全在人工关卡

## 八、三遍精读法（操作流程）
强制读三遍，每遍任务不同，禁止读一遍就开拆：
1. **抓动词**（~10min）："求…/给出…/分析…" → 只定问题类型，不联想方法
2. **抓约束**（~10min）：哪些条件不能违反，逐条列出
3. **抓数据接口**（~10min）：哪些量题目会给、哪些在附件（依据题面说明）、哪些要假设

## 九、Qi 卡片（每小问一张）
```
Q1 卡片
├── 自然语言描述: <一句话提炼>
├── 输入: 题目给定条件 / 附件数据(依据题面附件X的字段说明) / 上游问题结果(无则写"无"+理由)
├── 输出: 要交出的对象(含义、单位)
├── 约束: C1, C2, ...
├── 目标: 论文必须交付什么
├── 问题类型: 优化/预测/评价/机理/…
└── 难度估计: easy / medium / hard
```
**依赖证据原则**：只有题面、数学接口或业务机制支持时才建立小问间依赖；"题目未禁止"不构成复用证据，禁止为了"串起来"强行复用上游结果。

## 十、全局符号表（跨小问统一符号）
| 符号 | 含义 | 单位 | 中性角色(已知/待求/响应/待解释/待优化/规则/目标/约束) | 出现于 |
|---|---|---|---|---|
只收录在目标、约束或数据映射中实际使用的符号；缺必要符号要补齐，无用途符号要删除。同一符号禁止跨语境换义。

## 十一、题面附件信息引用边界
- 拆题阶段关于附件**只允许引用题面（含附录说明、字段说明）声明的内容**：提供了哪些字段、时间跨度声明、采样规则声明等
- **禁止打开附件数据文件做统计**（行数、缺失数、重复次数、分布、异常——全部是 data-profiler 的职责）
- 验收脚本机械拦截报告中的数据统计痕迹，见 scripts/verify_problem_spec.py

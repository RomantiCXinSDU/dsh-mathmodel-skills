# 顶刊标准拆题检查清单

> 对标顶级期刊论文的 Problem Statement / Research Questions 节：一个问题陈述合格的标志是——读者不看原文也能精确复现任务，且每个研究问题都可判定"答没答出来"。

## 目录
- 一、逐句覆盖（可追溯性）
- 二、研究问题改写（可判定性）
- 三、数学元素七类
- 四、约束分层
- 五、术语表
- 六、陷阱与歧义清单
- 七、文献定位（合规内）
- 八、提交人工关卡①的裁决项

## 一、逐句覆盖（可追溯性）
- [ ] 题目正文逐句编号，每句要么归入某个 R 编号，要么标注"背景信息"
- [ ] 每个 R 编号反向标注原文出处（页码/段落/句号）
- [ ] 附件说明、数据字典同样逐句过一遍（小问常藏在附件说明里）

## 二、研究问题改写（可判定性）
每小问改写为三要素齐全的研究问题：
- **输入**：给什么数据/条件
- **输出**：要交出什么（数值/模型/方案/判断）
- **成功判据**：怎样算答出来了（精度要求、格式要求、评价指标）
- 三要素缺任何一个 → 标"需人工裁决"，进第八节清单，禁止自行脑补

## 三、数学元素七类
- [ ] 已知量（题目给定，含附件数据）
- [ ] 未知量（要求的）
- [ ] 决策变量（可人为选择的）
- [ ] 状态变量（随过程演化的）
- [ ] 参数（需估计/标定的）
- [ ] 目标（优化/评价对象，单目标还是多目标）
- [ ] 约束（等式/不等式/逻辑约束）
- 某一类为空也要显式写"无"，防止漏想

## 四、约束分层
- **显性约束**：题目明文写的（逐条引用原文）
- **隐性约束**：领域常识/物理意义隐含的（如概率∈[0,1]、人数为整数、时间不可逆），逐条列出并标注"隐含"
- **需假设处**：题目没说清、建模必须补的，只标注"此处需假设：___"，不写假设内容

## 五、术语表
- [ ] 题目专有名词、缩写、行业术语逐条定义
- [ ] 每个概念指定全文唯一符号（中英文对照）
- [ ] 与附件字段名对齐（字段原名 ↔ 术语 ↔ 符号）

## 六、陷阱与歧义清单
常见陷阱模式（逐项排查）：
- 单位/量纲不统一（尤其附件数据）
- 时间口径（自然日/工作日、财年/日历年、时区）
- 分类变量的隐藏序关系
- "不少于/不低于/约"等模糊量词的具体数值含义
- 小问之间的依赖与数据复用限制
- 评价指标的导向性（题目暗示用什么指标评判结果）

## 七、文献定位（合规内）
- [ ] 用 scholar 查 2~3 篇该题型的方法综述或经典教材章节，只回答"这类问题的方法版图是什么"
- [ ] 记录文献信息（作者/年份/标题）供论文参考文献使用
- [ ] **红线**：不搜当届赛题的思路解析、现成答案；不浏览贴吧/知乎/CSDN/QQ群等赛题讨论

## 八、提交人工关卡①的裁决项
汇总所有"需人工裁决""待确认"条目，每条给出：
- 歧义点原文 + 出处
- 2~3 种可能解读
- 各解读对后续建模的影响
- 你的倾向性建议（供人参考，不替代人拍板）

## 九、三遍精读法（操作流程）
强制读三遍，每遍任务不同，禁止读一遍就开拆：
1. **抓动词**（~10min）："求最优…/预测…/评价…" → 定问题类型
2. **抓约束**（~10min）：哪些条件不能违反，逐条列出
3. **抓数据接口**（~10min）：哪些参数题目会给、哪些从附件提、哪些要假设

## 十、Qi 卡片（每小问一张）
```
Q1 卡片
├── 自然语言描述: <一句话提炼>
├── 输入: 题目给定参数 / 附件数据(附件X第Y列) / 上游问题结果(无则写"无"+理由)
├── 输出: 最终决策变量(含义、单位)
├── 约束: C1, C2, ...
├── 目标: 最小化/最大化 <什么>
├── 问题类型: 优化/预测/评价/机理/…
└── 难度估计: easy / medium / hard
```
**依赖证据原则**：只有题面、数学接口或业务机制支持时才建立小问间依赖；"题目未禁止"不构成复用证据，禁止为了"串起来"强行复用上游结果。

## 十一、全局变量表（跨小问统一符号）
| 符号 | 含义 | 单位 | 类型(决策/状态/参数/随机) | 出现于 |
|---|---|---|---|---|
只收录在目标、约束、数据映射或验证中实际使用的变量；缺必要变量要补齐，无用途变量要删除。同一符号禁止跨语境换义（反模式 B4）。

## 十二、数据 schema 速扫（拆题深度边界）
用 pandas 只扫四样：shape / dtypes / describe / isnull，输出"附件卡片"（行列数、时间跨度、缺失、异常、与变量的列映射）。**到此为止**——更深的数据画像和规则是 data-profiler / data-ruler 的活，不越界。
